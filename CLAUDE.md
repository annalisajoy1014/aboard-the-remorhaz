# Aboard the Remorhaz — Project Notes

## Deployment

This project is only viewable in production at:
**https://annalisajoy1014.github.io/aboard-the-remorhaz/**

There is no local dev server. All changes must be pushed to `origin/main` to be seen.
**Never hesitate to push to prod.** After every set of changes, run:

```
git add <files>
git commit -m "..."
git push origin main
```

GitHub Pages deploys within 1–2 minutes of a push.
